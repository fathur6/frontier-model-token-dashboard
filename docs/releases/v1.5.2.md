# v1.5.2 — In-App Update Prompt

## Highlights

- The menu can now tell you a newer release exists. A compact **vX.Y.Z available**
  row appears above the Usage chart and opens the GitHub release page when
  clicked.
- The check is silent and cheap: once every 24 hours the app fetches a small
  `version.json` manifest from this repository instead of calling the GitHub API,
  so it never hits rate limits and never runs during a refresh that could delay
  the menu.
- Dismissing a version hides it until an even newer one is published.

## Behaviour and safety

- A release is only offered when its semantic version is higher, or when the
  marketing version matches and its build number is higher. Equal and older
  manifests are ignored.
- Manifest values are validated before use: versions must be dotted numeric
  components, the build must be sane, and the release link must be **HTTPS on
  github.com**. A malformed, truncated or tampered manifest simply produces no
  prompt.
- Network failures are silent. A failed attempt is not recorded as a completed
  check, so the next refresh may retry; a successful check is throttled for 24
  hours.
- Overlapping checks collapse into one request, and nothing about the user is
  sent beyond a normal HTTPS request with the app version as its User-Agent.
- Quota, usage, cache and ledger state are untouched by an update check.

## Verification

- 260 tests pass across all four suites, including 12 new tests covering version
  comparison, manifest validation (unsafe URLs, malformed JSON, missing fields),
  throttle behaviour, failed-fetch retry, dismissal, and collapsed concurrent
  checks.
- The project was built, installed and exercised at 1.5.2 (build 8) with the
  manifest reporting the same version, which correctly produces no prompt.

- Users on 1.5.1 or earlier install this release manually once; from 1.5.2
  onwards new releases appear in the menu automatically.
- Automatic download and installation is still out of scope. That requires
  Sparkle with a stable Developer ID signature and notarization.
