# v1.5.3 — Frontier Model Token Dashboard

## Highlights

- The widget is now **Frontier Model Token Dashboard**. The repository moved to
  `fathur6/frontier-model-token-dashboard`; GitHub keeps the old URLs redirecting,
  and the previous `version.json` endpoint still resolves, so installed copies
  keep checking for updates.
- The menu shows a compact version readout in the same monospaced style used in
  Hermes: `# v1.5.3 (build 9)`. When a release is waiting it becomes
  `# v1.5.3 (update)` in green and opens the release page.

## Behaviour and safety

- The readout is purely informational unless an update is available; it reads
  the running bundle's `CFBundleShortVersionString` and `CFBundleVersion`, so it
  can never disagree with the installed build.
- Renaming the project does **not** change the bundle identifier
  (`com.opencode.widget.app`). Keychain credentials, the local ledger, cached
  history and the LaunchAgent therefore carry over untouched.
- Update checks now target the renamed repository's manifest. The old manifest
  URL continues to answer, so 1.5.2 installations still discover this release.

## Verification

- 260 tests pass across all four suites; Release build succeeds.
- Installed 1.5.3 (build 9) over 1.5.2 with app/ledger/cache backups; ledger
  integrity and chart data preserved.
- The manifest resolves from both the new and old raw URLs, and the app recorded
  a successful check with no spurious prompt (manifest matches the running build).

## Artifact

- Asset: `OpencodeWidget-1.5.3.dmg`
- Bundle version 1.5.3 (build 9)

- Signing: ad-hoc signed; not notarized.

## Notes

- The bundle file, executable and DMG keep the `OpencodeWidget` prefix so the
  installed app, LaunchAgent path and backup automation stay stable; only the
  display name and repository changed.

  signature and notarization.
